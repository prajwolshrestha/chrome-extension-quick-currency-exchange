# Currency Convert Chrome Extension

A beautiful, premium Chrome Extension for instant real-time currency conversion, designed with a sleek dark glassmorphism aesthetic, ultra-fast performance, and user-friendly micro-interactions.

---

## ✨ Features

- **Premium Dark Glassmorphism Theme**: An eye-safe, ultra-modern interface utilizing clean translucency, fine borders, and deep cosmic slate tones.
- **Instant Live Conversions**: Updates converted values synchronously as you type, powered by a free exchange rate API.
- **Top-right Refresh System**: Easily fetch the latest rates on-demand with a rotation-animated refresh button nested perfectly in the title bar.
- **Auto-Selection on Focus**: Instant productivity booster. Click on the input field, and the entire amount is automatically highlighted for rapid replacement.
- **Optimized Performance**: Highly efficient and lightweight code footprint utilizing structured modern Manifest V3 standards.
- **Zero Tracker Bloat**: Focuses strictly on functional utility with elegant, vanilla CSS variables and responsive SVG-driven typography.

## 🚀 Installation & Loading into Google Chrome

To install and run this extension locally in your Chrome browser, follow these simple steps:

### 1. Download or Export Project Files
- Ensure you have downloaded the generated extension code bundle (or extracted the downloaded ZIP).
- Inside the directory, you should see the following core extension files:
  ```text
  ├── manifest.json
  ├── popup.html
  ├── popup.js
  ├── popup.css
  └── icons/
      ├── icon16.png
      ├── icon48.png
      └── icon128.png
### 2. Open Chrome Extension Management
- Open a new tab in Google Chrome.
- Navigate to: chrome://extensions/ (or click the Extensions Puzzle Piece icon in the toolbar and select Manage Extensions).

### 3. Enable Developer Mode
- In the top-right corner of the Extensions dashboard, toggle Developer Mode to ON.

### 4. Load the Unpacked Extension
- In the top-left corner, click the Load unpacked button.
- Select the directory containing your extension files (the folder containing manifest.json).

🎉 That's it! The Currency Convert extension will now appear in your browser's toolbar/extensions menu.
